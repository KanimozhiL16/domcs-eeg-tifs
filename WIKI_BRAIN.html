Problem Statement

EEG-based biometric verification uses brainwave signals to authenticate individuals — a modality that is inherently hard to spoof. However, most existing work suffers from two critical flaws that make reported numbers overly optimistic:

❌ Problem 1 — Unrealistic Evaluation Protocols

Most papers train and test on data from the same cognitive task (e.g., both train and test on motor imagery). In the real world, a user enrolls at rest and must be verified during any cognitive activity — a fundamentally harder problem. Same-task protocols inflate accuracy by ~104% compared to cross-task.

❌ Problem 2 — Cognitive-State Entanglement

EEG signals are a superposition of who you are (identity) and what you are doing (cognitive state). When these are entangled, a model trained on resting EEG may fail to recognise the same person during a motor task — because the brain signal shifts dramatically between tasks.

DOMCS-EEG addresses both: a realistic B2T protocol (train on rest → test on 12 task runs) paired with explicit identity/cognitive-state disentanglement via multi-task learning.
💡

Key Contributions

B2T Protocol (Baseline-to-Task)

A locked evaluation protocol where the model is trained exclusively on resting-state EEG (R01, R02) and tested on 12 task runs (R03–R14), including motor imagery, reading, and other cognitive activities. This eliminates optimistic bias from same-task leakage.

Disentangled Multi-Component Supervised (DOMCS) Architecture

A lightweight 3-layer Conv1D network with two parallel heads: an identity head (z_id) that captures who the person is, and a cognitive-state head (z_cs) that captures what the person is doing. An orthogonality loss ensures the two representations don't collapse into each other.

Compound Loss Function

ArcFace + Supervised Contrastive + State Classification + Orthogonality — four complementary objectives that jointly push identity embeddings to be discriminative across subjects and robust across cognitive states.

KMeans Prototype Enrollment

Instead of a single enrollment vector per subject, k=3 cluster centroids capture intra-subject variability in resting-state EEG, improving robustness at verification time.

Protocol Inflation Analysis

Quantifies the "difficulty gap" between protocols: Random Split (+0%), Same Task (+104%), B2T (+296%). This provides practitioners with a concrete framework for choosing appropriate benchmarks.

Loss Functions

The total loss combines four objectives. Each serves a distinct purpose in learning discriminative, state-robust identity representations.

Ltotal = LArcFace + λSupCon·LSupCon + λState·LState + λOrth·LOrth
① ArcFace Loss — LArcFace

Purpose: Primary identity discrimination. Adds an angular margin m to the target class cosine before softmax, pushing identity embeddings to be angularly separated in embedding space.

HyperparameterValue
Scale (s)30.0
Margin (m)0.50
Weight (λ)1.0 (base loss)
② Supervised Contrastive Loss — LSupCon

Purpose: Pulls together all embeddings from the same subject (across windows/augmentations) and pushes apart embeddings from different subjects. Complements ArcFace by working in embedding space rather than classifier space.

HyperparameterValue
Temperature (τ)0.07
Weight (λSupCon)0.5 (train_60ep.py) / 0.1 (config YAML)
③ State Classification Loss — LState

Purpose: Forces the identity embedding z_id to encode enough information to predict the cognitive state (rest=0 or task=1). This adversarial signal prevents z_id from ignoring state and thus encourages disentanglement.

HyperparameterValue
ObjectiveCrossEntropy (binary: rest vs task)
Weight (λState)0.5 (train_60ep.py) / 0.1 (config YAML)
④ Orthogonality Loss — LOrth

Purpose: Minimises the squared dot product between z_id and z_cs. This explicitly prevents the two representation heads from encoding the same information, enforcing true disentanglement.

dot = (F.normalize(z_id, dim=1) * F.normalize(z_cs, dim=1)).sum(dim=1) L_orth = (dot**2).mean()
HyperparameterValue
Weight (λOrth)0.1

Training Protocol & Pipeline

B2T Split — Data Leakage Prevention

Core invariant: No test-run data (R03–R14) ever touches model selection or training. Validation is drawn exclusively from R01/R02 (resting state) via a stratified 80/20 split. The best checkpoint is chosen by lowest validation loss — entirely independent of the test set.

Val (20%)R01, R02 (stratified)Early stopping, best checkpoint selection
Test (held out)R03 – R14Final evaluation only — never seen during training

200-Epoch Convergence Analysis — Why 60 Epochs?

Figures: figures/FIG_LC_05_200epoch_analysis.png and figures/FIG_LC_200epoch_stability.png (Seed 1, 200-epoch training run).

A full 200-epoch training run was conducted on Seed 1 to empirically justify the 60-epoch cutoff. The four-panel figure reveals a clear convergence picture:

Loss Convergence

Both train and validation loss converge and stabilise by epoch ~60. After ep60, training loss continues a very slow decline (overfitting territory) while validation loss begins spiking with increasing amplitude.

Instability at Ep 192

A major validation loss spike is marked at epoch 192. The instability is driven by the state suppression loss component (negative-valued), which oscillates erratically after the model has already found its optimal identity embedding.

Accuracy Plateau

Training accuracy reaches ~97%, validation accuracy ~95% — both by epoch 60. No accuracy gain beyond epoch 60. The zoomed view (epochs 50–200) confirms the submitted model (ep60) lies at the last stable checkpoint before instability onset.

Component Breakdown

ArcFace loss converges by ~epoch 20. SupCon and Orthogonality losses converge by ~epoch 30–40. State suppression is the outlier — it continues oscillating, confirming that disentanglement objectives take longer to stabilise than identity objectives.

Epoch RangeBehaviourDecision
0 – 20Rapid ArcFace loss drop; acc rising fastWarm-up phase
20 – 60All components converging; val loss stableOptimal training window
60Last stable checkpoint; val acc plateaued at ~95%✅ Submitted model
60 – 192Val loss spikes growing; no acc improvementOverfitting / instability onset
192Major spike in val loss (instability peak)❌ Not usable
192 – 200Partial recovery; no net gain over ep60❌ No improvement
Conclusion: 60 epochs is the empirically optimal training duration. Training beyond this introduces validation instability driven by the state suppression loss without any corresponding gain in EER, AUC, or CRR. The early stopping patience of 10–15 epochs reliably catches this cutoff across all 5 seeds.

Enrollment & Verification Pipeline

Train on R01/R02 (Resting State)

Model learns identity from resting EEG only, with state supervision to disentangle identity from cognitive load.

Extract Resting-State Embeddings

Pass all R01/R02 windows through the frozen model to get z_id embeddings per subject.

KMeans Enrollment (k=3 prototypes per subject)

Cluster each subject's resting embeddings into k=3 centroids. This captures intra-subject variability (e.g., momentary attention shifts during resting).

Verify Against R03–R14 (Task State)

For each test window, compute cosine similarity to all enrolled prototypes. Score = max similarity over the claimed subject's k prototypes. EER is computed from genuine/impostor score distributions.

Security Analysis — IEEE TIFS Evaluation

For IEEE TIFS submission, a comprehensive adversarial security evaluation was conducted under the B2T protocol. Four threat scenarios are tested across three model variants (E1–E3), examining how the disentanglement architecture affects real-world attack resistance.

T1 — Skilled Forgery

Impostor submits resting-state EEG matching the enrollment cognitive state. Tests whether state-matching confers an advantage over random impostor attacks.

T2 — Enrollment Leakage

Attacker gains partial access to the target's enrollment data (10%, 25%, 50%, 100%). Tests how performance degrades as leakage fraction grows.

T3 — Noise Robustness

Additive White Gaussian Noise (AWGN) injected at SNRs from 30dB to 0dB, plus a band-limited artifact (60Hz + drift). Tests signal integrity requirements.

T4 — Adversarial Mimicry

White-box FGSM attack (20 steps) targeting the enrollment prototype. Tests whether gradient-based perturbations can fool the cosine-similarity verifier.

Key finding: DOMCS-EEG (E3) requires a 2.2× larger perturbation (α=0.173 vs 0.079) for white-box success, and achieves the largest forgery gap (Δ=−0.76pp), demonstrating that disentanglement meaningfully increases adversarial robustness despite a slightly higher baseline EER.

T1 — Skilled Forgery Analysis

A skilled forgery attack is where the impostor strategically submits resting-state EEG (matching the enrollment cognitive state) rather than arbitrary EEG. This tests whether cognitive-state matching gives the attacker an advantage.

Random vs. Skilled Forgery EER

MethodRandom EER (%)Skilled EER (%)Δ (pp)Ratio (Skilled/Random)
E1 — CNN + ArcFace (no decorr.)3.652.96−0.690.811
E2 — ArcFace + Lorth (decorr. only)3.622.94−0.680.812
E3 — DOMCS-EEG (Full)4.173.41−0.760.818
Interpretation of Δ < 0: All three models show lower EER when the impostor is skilled (Δ < 0). This is counterintuitive — it means skilled resting-state EEG actually makes it easier to distinguish the genuine vs impostor, because resting-state patterns are highly subject-specific. DOMCS-EEG has the largest |Δ| = 0.76pp, meaning its identity head is most sensitive to the subject-specific resting signature, making skilled forgery paradoxically more detectable.

T4 — Adversarial Attack Analysis

Two adversarial attack paradigms were evaluated: a black-box mimicry attack (50 random perturbation steps, no model access) and a white-box FGSM prototype attack (20 gradient steps, full model access targeting enrolled prototypes).

Mimicry Attacks — Black-box vs. White-box FGSM

ModelAttackStepsEER (%)AUC
E1 — ArcFaceBlack-box507.140.9773
E1 — ArcFaceWhite-box FGSM200.001.000
E2 — ArcFace+OrthBlack-box506.830.9777
E2 — ArcFace+OrthWhite-box FGSM200.001.000
E3 — DOMCS-EEGBlack-box505.060.9904
E3 — DOMCS-EEGWhite-box FGSM200.001.000
White-box EER = 0.00% means the FGSM gradient pushes the cosine similarity down (score decreases), not up — making the adversarial sample look less like the target, not more. This is a known artifact of L2-normalised embedding spaces: gradient-based perturbations that move the input off the data manifold tend to decrease cosine similarity, providing unexpected robustness.

White-box Embedding Attack Details

The embedding-space FGSM attack targets the cosine distance to enrolled KMeans prototypes. The key metric is alpha_success — the minimum perturbation magnitude needed to achieve ASR = 100%.

Modelα (success)ASR (%)Embedding GapThreshold τ
E1 — ArcFace0.0787100.00.73200.2489
E2 — ArcFace+Orth0.0787100.00.73090.2500
E3 — DOMCS-EEG0.1730100.00.70570.4579
DOMCS-EEG requires 2.2× larger perturbation (α = 0.173 vs 0.079) to achieve full ASR. This is because: (1) the identity embedding is trained with a higher cosine margin (τ = 0.4579 vs ~0.25), and (2) the orthogonality constraint forces the identity head to encode only subject-specific features, making the embedding manifold more structured and harder to leave with small gradient steps. The higher verification threshold τ is a direct consequence of better genuine/impostor separation.
Security Interpretation Summary
  • Black-box mimicry (50 steps): DOMCS-EEG achieves EER = 5.06% — significantly better than E1 (7.14%) and E2 (6.83%). Disentanglement helps black-box robustness.
  • White-box FGSM (20 steps): All models reject FGSM attacks (EER = 0%) due to the L2-normalisation geometry. Not a vulnerability.
  • Embedding perturbation budget: DOMCS-EEG needs 2.2× more budget (α = 0.173) — a meaningful security margin over baselines.
  • Verification threshold: τ = 0.458 (DOMCS-EEG) vs τ ≈ 0.25 (baselines) — the larger margin directly translates to adversarial robustness.

Quickstart

1. Install Dependencies

pip install -r requirements.txt

2. Evaluate with Pretrained Checkpoint (Seed 1)

python scripts/evaluate.py --checkpoint checkpoints/seed_1/model_best.pt # Expected: EER=3.73%, AUC=0.9926, CRR=87.03%

3. Load Model in Python

import torch from domcs_eeg.model import DOMCSEEG model = DOMCSEEG() ckpt = torch.load('checkpoints/seed_1/model_best.pt', map_location='cpu', weights_only=False) # Remap keys (backbone. prefix in training checkpoint) state = {k.replace('backbone.', ''): v for k, v in ckpt['model_state'].items()} model.load_state_dict(state, strict=False) model.eval() # Get identity embedding from raw EEG x = torch.randn(1, 64, 256) # (batch, channels, time) z_id = model.get_identity_embedding(x) # → (1, 128) L2-normalised

4. Reproduce All Paper Results

bash scripts/reproduce_paper.sh

Reproducibility Notes

Full Reproducibility: All 5 seeds are locked. Results in the paper were obtained with torch.manual_seed(seed) and np.random.seed(seed) set before each run. GPU determinism may introduce minor floating-point differences (<0.01% EER) depending on hardware.

Before Running — Update Paths

Edit scripts/core_framework.py or scripts/train_60ep.py and update:

CFG = { "ROOT": "/your/data/root", "NPZ_PATH": "/your/path/EEGMMIDB_win2s_step1s_fs128.npz", "EXP_ROOT": "/your/experiments/output", "GPU_ID": "0", # change to your available GPU ... }
